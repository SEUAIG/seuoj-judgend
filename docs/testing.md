# 测试说明

本文档详细描述 SEU AIJ Judge-Endpoint 项目的测试策略、测试用例和测试环境。

## 测试策略

### 测试层次

项目采用多层测试策略：

| 测试类型 | 位置                  | 工具            | 目的             |
|------|---------------------|---------------|----------------|
| 单元测试 | 模块内部 `#[cfg(test)]` | Rust 内置       | 测试单个函数/方法      |
| 集成测试 | `tests/` 目录         | `axum-test`   | 测试 API 接口和模块集成 |
| 功能测试 | 手动/脚本测试             | `curl`, 自定义脚本 | 测试完整功能流程       |

## 测试环境

### 环境要求

#### 必需组件

- Rust 工具链 1.70+
- 所有支持的编程语言工具链
- 测试题目数据 (`assets/problems/p01/`)
